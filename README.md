# ⚡ EDU CONNECT — Institute Management Portal

EDU CONNECT is a full-stack institute management system designed to centralize student data, automate attendance workflows, enable secure role-based operations, and streamline administrative communication.

It provides powerful analytics, subject-wise tracking, OTP-secured authentication, and AI-assisted notice generation — making institutional data handling efficient, structured, and intelligent.

# 🛠 Tech Stack

### 🎨 Frontend
- React.js  
- Axios  
- Chart.js  

### ⚙️ Backend
- Node.js  
- Express.js  

### 🗄 Database
- MongoDB  
- Redis (OTP caching)

### 🔐 Authentication & Security
- JWT Authentication  
- bcrypt Password Hashing  
- OTP Verification System  

### 📧 Integrations
- Nodemailer (emails & OTPs)  
- Gemini API (AI notice rephrasing)
